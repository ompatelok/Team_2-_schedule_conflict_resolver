Team deliverable

Documentation

Complete workflow, rules, and team contributions for the hackathon.

Problem

Given overlapping events with priorities, create a conflict-free schedule and explain every change using explicit rules.

Workflow

Input → Validation → AI Resolve → Verification → Explanation

The Rules (R1-R7)

  • R1: Normalize to UTC, use half-open intervals
  • R2: Hard constraints (fixed, mandatory, duration, window)
  • R3: Dependencies and inherited priority
  • R4: Move before drop
  • R5: Lower priority yields slot
  • R6: Tie-break (mandatory, earlier time, alphabetical)
  • R7: Placement (earliest free slot after original start)
